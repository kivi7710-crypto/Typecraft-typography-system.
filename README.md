TypeCraft - Typography Scale & Visual Design System

📌 Project Overview

TypeCraft is a modern typography and visual design system created using Figma. It demonstrates how typography, visual hierarchy, colour palettes and consistent spacing contribute to attractive and user-friendly interfaces.

🎨 Design Features

- Typography hierarchy and font scale
- Display headings and body text styles
- Visual hierarchy using size, weight and colour
- 8-point spacing grid system
- Primary, secondary and neutral colour palettes
- Contrast and alignment principles
- Reusable UI components
- Responsive desktop and mobile layouts

🛠 Tools Used

- Figma
- UI/UX Design
- Auto Layout
- Components and Variants

📐 Design Principles

- Consistency
- Readability
- Visual Hierarchy
- Proper Alignment
- Colour Contrast
- Spacing and Balance
